# A request ended inside an internal function leaves what that function held
# behind, and nothing frees it. The worker is retired for it when the heap grew
# by more than a threshold between two moments with no request in flight, and not
# otherwise: a worker that kept a lot on purpose in plain code is left alone, and
# so is one that then has a few hundred rows left behind by a sort — the growth
# that came before it is not counted against it, which is why the pairs are in
# this order. The time limit ends them, which no failure counter sees.
