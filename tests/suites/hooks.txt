# description: Runtime hooks in worker mode — request/task fiber multiplexing of native sleep

# These two lines belong together and must stay at the top of this profile, in
# this order. PHP_WORKERS=1 here, so every request lands on the same worker:
# the first one gives its request fiber a completed request WITHOUT suspending,
# and the second then runs on that recycled fiber with a never-written state
# snapshot — the case where all of the second test's checks are live. Any
# suspending request first (every hooks/* test awaits or sleeps) leaves a
# half-benign snapshot behind instead: its header list and status come back
# valid, and only the $_REQUEST check would still fail on a broken build.
# A replacement opener must therefore satisfy both requirements — never suspend,
# and not mention $_REQUEST. The second one is not a property of this suite but
# of an open worker-mode defect: $_REQUEST is a lazily built auto-global that a
# worker materialises for the first script referencing it and then never rebuilds,
# so an earlier mention would leave the test below asserting an earlier request's
# $_REQUEST and failing for the wrong reason. Drop that half of the rule once the
# defect is fixed. strict=1 turns "served on a fresh fiber" into a failure, which
# here is a real invariant, not a coin flip.

worker/test_request_state_after_reuse >> ?probe=42&strict=1
