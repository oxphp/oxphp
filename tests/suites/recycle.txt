# Order is the test. Each line is one request to a single worker, so a probe
# that reports requestCount() == 1 is reporting a worker that booted after the
# lines above it ran. The `log ~` lines send no request: each searches only what
# the latest block of requests above it wrote — the lines since the last blank
# line before them — so each block answers for its own lines.

recycle/test_recycle_baseline

# A worker that passes its memory ceiling is recycled after the request that
# took it there. The probe settles that it happened and why; the log lines are
# what an operator meets. The worker's own line names the reason in words with
# the two numbers it compared, and the pool's line is the one for a recycle: a
# build that still read a finished thread as a dead one writes "Dead workers
# detected" instead and has no line to match the last needle.
