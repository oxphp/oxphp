---
title: Идентификаторы запросов
description: Уникальные идентификаторы запросов для трассировки и корреляции
---

Каждый запрос, обработанный OxPHP, получает уникальный идентификатор. Этот идентификатор отображается в журналах доступа, журналах ошибок и заголовках ответов, предоставляя единое значение для корреляции запроса на всех уровнях стека.

## Настройка

Генерация идентификаторов запросов всегда включена. Настройка не требуется.

## Как это работает

Обработчик событий `RequestIdGenerator` выполняется с приоритетом **-100** (наименьшее значение приоритета, то есть он выполняется первым). Он либо сохраняет входящий идентификатор запроса, либо генерирует новый.

### Проброс

Если входящий запрос содержит заголовок `X-Request-ID`, его значение используется как есть. Это позволяет вышестоящим балансировщикам нагрузки или API-шлюзам назначать идентификаторы запросов, которые пробрасываются через OxPHP.

### Генерация

Если заголовок `X-Request-ID` отсутствует, OxPHP генерирует идентификатор в формате:

```
{timestamp:08x}{counter:08x}
```

- **timestamp** (8 шестнадцатеричных символов): текущая Unix-метка времени в секундах, усечённая до 32 бит
- **counter** (8 шестнадцатеричных символов): процессный атомарный счётчик, использующий полный диапазон `u32`

Результат — 16-символьная строка в нижнем регистре шестнадцатеричной записи. Например: `67890abc00000042`.

Счётчик использует порядок памяти `Relaxed`, поскольку уникальность гарантируется атомарным инкрементом — связь «произошло до» с другими данными не требуется.

### Заголовок ответа

Идентификатор запроса включается в каждый HTTP-ответ в виде заголовка `X-Request-ID`. Он устанавливается обработчиком заголовков сервера во время события `ResponseBuilding`.

## Доступ к идентификатору запроса в PHP

Идентификатор запроса доступен в PHP через функцию `oxphp_request_id()`, предоставляемую PHP-расширением OxPHP:

```php
<?php
$requestId = oxphp_request_id();
header("X-Correlation-ID: $requestId");
error_log("Processing request $requestId");
```

Функция возвращает ту же 16-символьную шестнадцатеричную строку (или проброшенное значение), которая отображается в заголовке ответа и журналах доступа.

## Корреляция в журнале доступа

Каждая запись журнала доступа включает поле `request_id`:

```json
{
  "request_id": "67890abc00000042",
  "method": "GET",
  "path": "/api/users",
  "status": 200,
  "duration_us": 1234,
  "remote_addr": "10.0.0.1:54321"
}
```

Вы можете фильтровать журналы по идентификатору запроса, чтобы проследить полный жизненный цикл отдельного запроса, включая ошибки PHP, ссылающиеся на тот же идентификатор.
