# Идентификаторы запросов

Каждый запрос, обрабатываемый OxPHP, получает уникальный идентификатор для трассировки и корреляции логов. Идентификатор отображается в заголовках ответа и журналах доступа, предоставляя единое значение для отслеживания запроса на каждом уровне вашего стека.

## Как это работает

1. OxPHP присваивает уникальный идентификатор каждому входящему запросу до начала любой другой обработки.
2. Если клиент отправляет заголовок `X-Request-ID` — например, от балансировщика нагрузки или API-шлюза — OxPHP проверяет и сохраняет это значение. Для прохождения проверки заголовок должен содержать от 1 до 64 символов и состоять только из буквенно-цифровых символов, дефисов (`-`), подчёркиваний (`_`) или точек (`.`). При неудачной проверке OxPHP генерирует новый идентификатор.
3. Если допустимый заголовок `X-Request-ID` отсутствует, OxPHP генерирует 20-символьный шестнадцатеричный идентификатор в нижнем регистре (например, `67890abc12341a2b0042`). Идентификатор кодирует временную метку, уникальное для процесса значение и монотонный счётчик, что делает коллизии между контейнерами и перезапусками крайне маловероятными.
4. Идентификатор отображается в заголовке ответа `X-Request-ID` в каждом ответе.
5. Когда включено журналирование доступа, идентификатор появляется в поле `request_id` каждой записи журнала.
6. PHP-скрипты могут читать идентификатор через `oxphp_request_id()`.

## Заголовок ответа

Каждый HTTP-ответ от OxPHP включает заголовок `X-Request-ID`:

```http
HTTP/1.1 200 OK
X-Request-ID: 67890abc12341a2b0042
Content-Type: text/html; charset=utf-8
```

Когда вышестоящий балансировщик нагрузки или шлюз передаёт `X-Request-ID` во входящем запросе, то же значение возвращается в ответе, обеспечивая сквозную трассируемость по всей инфраструктуре.

## Примеры PHP

Читайте текущий идентификатор запроса из PHP с помощью `oxphp_request_id()`:

```php
<?php
$requestId = oxphp_request_id();

// Включить в логи приложения для корреляции
$logger->info('Processing order', [
    'request_id' => $requestId,
    'order_id'   => $orderId,
]);
```

Передавайте идентификатор запроса нижестоящим сервисам для сохранения трассируемости при API-вызовах:

```php
<?php
$requestId = oxphp_request_id();

$ch = curl_init('https://api.example.com/users');
curl_setopt($ch, CURLOPT_HTTPHEADER, [
    "X-Request-ID: $requestId",
]);
$response = curl_exec($ch);
curl_close($ch);
```

## Примеры

При включённом журнале доступа каждая запись содержит поле `request_id`:

```json
{
  "timestamp": "2026-02-11T12:34:56.789Z",
  "level": "INFO",
  "fields": {
    "request_id": "67890abc12341a2b0042",
    "method": "GET",
    "path": "/api/users",
    "status": 200,
    "duration_us": 1234,
    "remote_addr": "10.0.0.1:54321",
    "message": "request completed"
  }
}
```

Фильтруйте агрегатор логов по `request_id`, чтобы отследить полный жизненный цикл одного запроса, включая любые PHP-ошибки или записи журнала приложения, ссылающиеся на тот же идентификатор.

## Устранение неполадок

### В ответах отсутствует заголовок `X-Request-ID`

Это неожиданная ситуация — OxPHP добавляет заголовок к каждому ответу. Если заголовок отсутствует, промежуточный прокси может его удалять.

**Проверьте:** Протестируйте напрямую против OxPHP без прокси на пути:

```bash
curl -v http://localhost:8080/ 2>&1 | grep -i x-request-id
```

### Идентификатор от вышестоящего сервиса не сохраняется

Входящее значение `X-Request-ID` может не проходить проверку. OxPHP отклоняет идентификаторы, которые пусты, длиннее 64 символов или содержат символы, отличные от буквенно-цифровых, дефисов, подчёркиваний и точек.

**Проверьте:** Изучите значение, отправляемое вышестоящим сервисом, и убедитесь, что оно соответствует требованиям к символам и длине. Частые проблемы — значения с косыми чертами, пробелами или фигурными скобками.

### `oxphp_request_id()` возвращает пустую строку

Эта функция доступна только в OxPHP. При запуске того же PHP-кода под PHP-FPM или в CLI-режиме функция не определена. Защитите вызовы проверкой совместимости:

```php
<?php
$requestId = function_exists('oxphp_request_id')
    ? oxphp_request_id()
    : ($_SERVER['HTTP_X_REQUEST_ID'] ?? uniqid('', true));
```
