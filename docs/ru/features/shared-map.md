# Shared\Map

`OxPHP\Shared\Map` — это конкурентный map, живущий в общем реестре и видимый каждому PHP-воркеру в процессе. Это примитив первого выбора, когда двум воркерам — или обработчику запроса и фоновой задаче — нужно разделять изменяемое состояние, переживающее жизненный цикл запроса.

## Обзор

- **`int|string → mixed`.** Ключи — PHP-целые или строки, хранятся **раздельно** (`123` и `"123"` — разные ключи; нет приведения ключей в стиле PHP-массивов). Строковые ключи **бинарно-безопасны** — хранятся как непрозрачные байты (как PHP-массивы / Go / Redis), поэтому не-UTF-8 ключи (включая встроенный NUL) round-trip'ятся точно. Значения — любой скаляр, массив скаляров/массивов или другой экземпляр `Shareable`.
- **`null` означает отсутствие — никогда не хранимое значение.** Запись значения `null` бросает `TypeException`; возврат `null` всегда означает «такого ключа нет». Это устраняет классическую неоднозначность «`get()` вернул null» в корне (тот же выбор делают `java.util.concurrent.ConcurrentHashMap` и `sync.Map` в Go).
- **Один линеаризуемый условный примитив.** `compareAndSet` покрывает атомарные вставку / замену / удаление через `null`-сентинел отсутствия; постройте на нём любой read-modify-write.
- **Конкурентный.** Записи от разных воркеров не требуют внешней блокировки; операции per-key атомарны на уровне шарда.
- **Cycle-safe.** Сохранение `Shareable`, который в итоге достигнет обратно этого Map, отклоняется с `CycleException` до какой-либо мутации — нет утечек на отклонённом пути.
- **Ограничен приблизительным мягким потолком.** `maxEntries` — это OOM-страховочный потолок, а не точный учёт.

## Справочник API

```php
namespace OxPHP\Shared;

final class Map implements Shareable
{
    public function __construct(?int $maxEntries = null);   // null = без ограничения; <= 0 бросает TypeException

    // чтения
    public function get(int|string $key): mixed;            // null ⟺ отсутствует
    public function getMany(iterable $keys): \Iterator;     // лениво; пропускает отсутствующие ключи
    public function count(): int;                           // полосовой, слабосогласованный
    public function maxEntries(): ?int;

    // записи
    public function set(int|string $key, mixed $value): void;
    public function setIfAbsent(int|string $key, mixed $value): mixed;  // prev; null ⟺ вставлено
    public function setMany(iterable $entries): int;
    public function remove(int|string $key): bool;          // существовал?
    public function removeMany(iterable $keys): int;
    public function clear(): int;                           // удалено записей

    // возвращающие значение
    public function swap(int|string $key, mixed $value): mixed;  // prev; null ⟺ отсутствовал
    public function pop(int|string $key): mixed;                 // prev; null ⟺ отсутствовал

    // условный (единственный линеаризуемый примитив)
    public function compareAndSet(int|string $key, mixed $expected, mixed $new): bool;

    // итерация
    public function forEach(callable $fn): void;            // слабосогласованная; колбэк выполняется без блокировки

    public function id(): int;
}
```

| Метод          | Применение                                                                           |
|----------------|--------------------------------------------------------------------------------------|
| `__construct`  | Создать с опциональным `maxEntries` cap (null = без ограничения; `<= 0` бросает).     |
| `get`          | Получить по ключу; `null` ⟺ отсутствует.                                              |
| `getMany`      | Лениво стримить `key => value` для известных ключей; отсутствующие пропускаются (см. ниже). |
| `count`        | Приблизительное число записей (слабосогласованно при конкурентных записях).           |
| `maxEntries`   | Сообщает настроенный cap (или `null`, если без ограничения).                          |
| `set`          | Вставить или заменить; предыдущее значение не материализуется.                        |
| `setIfAbsent`  | Атомарная вставка-если-отсутствует; возвращает существующее значение или `null`, если вставила. |
| `setMany`      | Массовая вставка из любого iterable; возвращает число записанных.                     |
| `remove`       | Удалить ключ; возвращает, существовал ли он (значение не материализуется).            |
| `removeMany`   | Массовое удаление; возвращает число фактически удалённых.                             |
| `clear`        | Сбросить каждую запись (отпустив удержания вложенных `Shareable`); возвращает число удалённых. |
| `swap`         | Перезаписать и вернуть предыдущее значение (`null` ⟺ отсутствовал).                   |
| `pop`          | Удалить и вернуть предыдущее значение (`null` ⟺ отсутствовал).                        |
| `compareAndSet`| Атомарные вставка / замена / удаление в зависимости от текущего содержимого (см. ниже). |
| `forEach`      | Слабосогласованный обход; колбэк выполняется без удержания блокировки.                |
| `id`           | Числовой идентификатор реестра; полезен для логов + `/__ox_shared/entry?id=…`.        |

Здесь нет `has()`, `update()`, `getOrSet()`, `keys()`, `trySet()`, `updateMany()`, и класс **не** реализует `Countable` — см. [Миграция со старой поверхности](#миграция-со-старой-поверхности).

## Модель «null означает отсутствие»

`null` повсюду зарезервирован как сентинел отсутствия:

- `set` / `swap` / `setIfAbsent` со значением `null` → `TypeException`.
- `get` / `swap` / `pop` / `setIfAbsent`, возвращающие `null` ⟺ ключ отсутствовал.
- В `compareAndSet` `null` с любой стороны означает «отсутствует» (а не «сохранить null»).

Если нужно записать «нет значения», удалите ключ (или используйте отсутствие ключа), а не храните `null`. Поскольку нет `has()` и нет гонки одновременных `has()`+`get()`, наличие проверяется атомарно одним `get($k) !== null`.

## compareAndSet — условный примитив

```php
$map->compareAndSet($key, expected: null, new: $v);    // вставить iff отсутствует (= setIfAbsent, возвращает bool)
$map->compareAndSet($key, expected: $a,   new: $b);    // заменить iff текущее === $a
$map->compareAndSet($key, expected: $a,   new: null);  // удалить  iff текущее === $a
```

Возвращает `true` iff swap был применён. Равенство — **по содержимому**: скаляры по значению, строки и массивы по сериализованным байтам, а вложенные `Shareable`-значения — по идентичности реестра. Равенство массивов совпадает с PHP `===` для обычных случаев (списки, массивы только с int- или только со string-ключами); массивы, **чередующие** int- и string-ключи, сравниваются по нормализованной форме хранения, поэтому конкретный порядок int/string не различается (Map всё равно переупорядочивает такие массивы при чтении). Постройте read-modify-write как явный retry-цикл — и держите замыкание чистым, поскольку под конкуренцией оно выполняется более одного раза:

```php
do {
    $cur = $map->get('counter');          // null, если отсутствует
    $next = ($cur ?? 0) + 1;
} while (!$map->compareAndSet('counter', $cur, $next));
```

ABA-опасности здесь нет: хранилище контентно-адресуемо (значение, равное по содержимому, *и есть* то же значение для хранилища значений), а идентичность вложенных `Shareable` использует монотонные, никогда не переиспользуемые id реестра. Для защищённой от стампеда ленивой инициализации используйте [`Shared\Once`](shared-once.md); для пулируемых ресурсов — [`Shared\Pool`](shared-pool.md).

## Модель памяти — где происходят копии

Значения хранятся как сериализованное представление, **а не** как zval'ы — поэтому «zero-copy» к значениям не применяется:

| Операция                          | Сериализация в общую кучу | Материализация предыдущего значения в zval |
|-----------------------------------|:-------------------------:|:------------------------------------------:|
| `set` / `setMany`                 | да                        | нет                                        |
| `remove` / `removeMany`           | —                         | нет                                        |
| `setIfAbsent`                     | да                        | только если предыдущее значение существует |
| `swap` / `pop`                    | да / —                    | да                                         |
| `get` / `getMany`                 | (только ключ)             | да                                         |
| `compareAndSet`                   | да (`$new`)               | нет                                        |

Сериализация на пути записи неизбежна для любого значения, входящего в общую память. Обратное чтение в свежий zval оплачивается **только** методами, возвращающими предыдущее/найденное значение — поэтому `set`/`remove` — это «без материализации возврата», а не «бесплатно». Исключение — **вложенное `Shareable`**-значение: оно хранится по ссылке (id + инкремент refcount), а не глубоко копируется.

## Конкурентность

- **`count()` слабосогласован.** Счётчики записей распределены по шардам (полосовой учёт) и суммируются при чтении; результат точен, когда map в покое, и близкое приближение при конкурентных записях (тот же контракт, что у `ConcurrentHashMap::size`). Полосовой учёт держит записи в стороне от единственного горячего счётчика.
- **`maxEntries` — мягкий потолок.** Он проверяется по полосовой сумме, поэтому при конкурентных вставках map может превысить лимит вплоть до числа шардов прежде, чем отклонит новый ключ с `CapacityException`. Считайте его OOM-страховочным бюджетом, а не точным учётом. Перезапись существующего ключа всегда успешна на потолке. Вытеснения **нет** — кэш с вытеснением LRU/TTL — это другой примитив.
- **`forEach` выполняет колбэк без удержания блокировки.** Он снимает ключи по одному шарду за раз, отпускает шард, затем повторно читает каждое значение и вызывает `$fn(key, value)`. Ключи, удалённые между снимком и вызовом, пропускаются; ключи, добавленные после снимка шарда, могут быть пропущены; значения могут быть свежее времени снимка. Верните `false` из колбэка, чтобы остановиться досрочно. Поскольку снимаются только ключи, медленный колбэк никогда не удерживает удалённые значения.

## Примеры

### Разделяемый кэш конфигурации

```php
<?php
$config = new OxPHP\Shared\Map(maxEntries: 1024);

// Прогреть один раз при bootstrap приложения.
$config->setMany([
    'rate_limit.default_rpm' => 600,
    'feature.new_checkout'   => true,
    'timeout.downstream_ms'  => 250,
]);

// Любой обработчик запроса читает без конкуренции; null ⟺ не сконфигурировано.
$rpm = $config->get('rate_limit.default_rpm') ?? 60;
```

### Per-tenant rate limiter

```php
<?php
$buckets = new OxPHP\Shared\Map(maxEntries: 50_000);

$key  = "tenant:{$tenantId}";
$prev = $buckets->setIfAbsent($key, ['tokens' => 100, 'refill_at' => time() + 60]);
// $prev === null ⟺ мы создали bucket; иначе он держит существующий.

$state = $buckets->get($key);
if ($state['tokens'] === 0) {
    throw new RateLimitException();
}
```

### Координация счётчиков между воркерами

```php
<?php
$counters = new OxPHP\Shared\Map();
$counters->set('requests_handled', new OxPHP\Shared\Counter());

// Любой воркер инкрементирует через сохранённый Shareable (хранится по ссылке).
$counters->get('requests_handled')->inc();
```

### Итерация большого map

```php
<?php
$sessions->forEach(function (int|string $key, mixed $value): bool|null {
    if ($value['expires_at'] < time()) {
        // безопасно: forEach не держит блокировку во время колбэка
        return null; // продолжаем
    }
    return null;
});

// Или лениво прочитать известное подмножество, останавливаясь досрочно:
foreach ($cache->getMany($hotKeys) as $key => $value) {
    if (enoughCollected()) break;     // оставшиеся ключи никогда не материализуются
    handle($key, $value);
}
```

## Семантика и подводные камни

### Массивы копируются при чтении

```php
<?php
$m = new OxPHP\Shared\Map();
$m->set('cfg', ['timeout' => 5, 'retries' => 3]);

$cfg = $m->get('cfg');
$cfg['timeout'] = 10;     // мутирует только возвращённую копию
// $m->get('cfg')['timeout'] всё ещё 5
```

Чтобы атомарно обновить значение-массив, прочитайте его, измените копию и зафиксируйте через `compareAndSet` (повторяя при конфликте), либо храните независимо меняющиеся поля как вложенные `Shared\Counter` / `Shared\Map`.

### Удержания вложенных Shareable автоматичны

```php
<?php
$map     = new OxPHP\Shared\Map();
$counter = new OxPHP\Shared\Counter(10);
$map->set('c', $counter);

$retrieved = $map->get('c');           // та же идентичность Shareable
$retrieved->inc();                      // мутация видна и через $counter
echo $counter->get();                   // 11

$counter2 = $map->pop('c');             // Map отпускает своё удержание, возвращает значение
$counter2->inc();                       // всё ещё жив через возвращённую обёртку
```

### Обнаружение циклов отклоняет до мутации

```php
<?php
$a = new OxPHP\Shared\Map();
$b = new OxPHP\Shared\Map();
$a->set('b', $b);                       // ок

try {
    $b->set('a', $a);                   // замыкает петлю
} catch (OxPHP\Shared\CycleException $e) {
    // message: "cycle would form: #… → #… (inserting into #…)"
}

$b->get('a');                           // null — $b не тронут, утёкших удержаний нет
```

Вложенные ссылки внутри массивов тоже проверяются. Обходчик ограничен `SHARED_CYCLE_DETECT_DEPTH` (по умолчанию 16) и `SHARED_CYCLE_DETECT_EDGES` (по умолчанию 10 000); очень большие графы всплывают как `CycleException` с `bounds exceeded` — поднимайте env-настройки или разбивайте граф.

### Cap на размер одного значения

Одно значение, чей сериализованный размер превышает `SHARED_MAX_VALUE_SIZE` (по умолчанию 1 MiB), отклоняется с `ValueTooLargeException`. Это защищает от аллокационной бомбы со стороны PHP-входа. Применяется ко всякому пути записи (`set`, `setIfAbsent`, `swap`, `compareAndSet`, `setMany`).

### Пакетные операции атомарны per-key, а не per-batch

`setMany`, `getMany` и `removeMany` применяют операции по одному ключу за раз. Если `setMany` упирается в `CapacityException`, `CycleException` или `ValueTooLargeException` посреди пути, предыдущие ключи остаются сохранёнными — частичный успех намеренный. Оборачивайте map в `Shared\Mutex`, если нужна семантика «всё-или-ничего».

## Миграция со старой поверхности

Это ломающий редизайн без слоёв совместимости:

| Старое                                | Новое                                                            |
|---------------------------------------|------------------------------------------------------------------|
| `has($k)`                             | `get($k) !== null` (атомарно — нет гонки `has`/`get`)            |
| `get($k, $default)`                   | `get($k) ?? $default`                                            |
| `trySet($k, $v): bool`                | `setIfAbsent($k, $v): mixed` (возвращает prev; `null` ⟺ вставлено) |
| `remove($k)` (возвращал prev)         | `remove($k): bool`, или `pop($k)`, чтобы получить значение        |
| `update($k, $fn)`                     | retry-цикл `compareAndSet`, или `Shared\Once` для once-init       |
| `getOrSet($k, $fn)`                   | `setIfAbsent`, или `Shared\Once` / `Shared\Pool` по случаю        |
| `updateMany(...)`                     | цикл из `compareAndSet`                                          |
| `keys(): array`                       | `forEach(...)`, или `getMany($knownKeys)`                         |
| `count($map)` (Countable)             | `$map->count()`                                                 |
| хранение значения `null`              | используйте отсутствие ключа / `remove`                          |

## Исключения

Все методы, которые могут отказать, бросают подклассы `OxPHP\Shared\SharedException`:

| Исключение               | Бросается                                                                  |
|--------------------------|---------------------------------------------------------------------------|
| `CapacityException`      | Новый ключ за пределом `maxEntries` (`set` / `setIfAbsent` / `compareAndSet` / `setMany`). |
| `ValueTooLargeException` | Значение сверх cap на одно значение (`SHARED_MAX_VALUE_SIZE`).             |
| `CycleException`         | Запись, которая замкнула бы цикл достижимости (`extends TypeException`).    |
| `TypeException`          | Значение `null`; нехранимое значение (объект/замыкание/ресурс); ключ не int/string; `maxEntries <= 0`. |
| `StaleHandleException`   | Вызов метода на хэндле, чья запись реестра была вытеснена.                 |

## Наблюдаемость

Каждый Map виден через внутренний API:

- `GET /__ox_shared/summary` — агрегированные счётчики по типам, включая `Map`.
- `GET /__ox_shared/entries` — список всех записей с id / type / refcount / mem_bytes.
- `GET /__ox_shared/entry?id=N` — детали per-instance для Map включают `key_count`, `max_entries`, `saturation` и `sample_keys` (обрезано preview-лимитом).
- `GET /__ox_shared/graph?id=N[&depth=D][&edges=E]` — BFS-обход исходящих Shareable-ссылок; удобно после `CycleException`.

Prometheus показывает per-Map gauge'ы на `/metrics`:

| Метрика                                    | Смысл                                      |
|--------------------------------------------|--------------------------------------------|
| `oxphp_shared_map_entries{map_id="…"}`     | Текущее (приблизительное) число ключей.    |
| `oxphp_shared_map_max_entries{map_id="…"}` | Настроенный cap (0, если без ограничения). |
| `oxphp_shared_map_saturation{map_id="…"}`  | `entries / max_entries`, 0 без ограничения. |

## Конфигурация

| Переменная                       | По умолчанию | Эффект                                                                |
|---------------------------------|---------|-----------------------------------------------------------------------|
| `SHARED_MAX_ENTRIES`            | 100 000 | Глобальный cap на все Shared-записи вместе.                            |
| `SHARED_MAX_BYTES`              | 1 GiB   | Глобальный cap на оценочную память по всем Shared-записям.             |
| `SHARED_MAX_VALUE_SIZE`         | 1 MiB   | Cap на сериализованный размер одного значения; большие значения бросают `ValueTooLargeException`. |
| `SHARED_CYCLE_DETECT_DEPTH`     | 16      | Максимальная глубина BFS при проверке циклов. Поднимайте для глубоких легитимных графов. |
| `SHARED_CYCLE_DETECT_EDGES`     | 10 000  | Максимум пройденных рёбер при проверке циклов. Поднимайте для плотных легитимных графов. |
| `SHARED_PREVIEW_ARRAY_LIMIT`    | 20      | Число записей, семплируемых в `/entry?id=…` `sample_keys`.             |
| `SHARED_INTROSPECTION_ENABLED`  | true    | Переключает API `/__ox_shared/*`.                                      |
