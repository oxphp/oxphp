# Shared\Once

`OxPHP\Shared\Once` запускает инициализирующее замыкание ровно один раз на весь процесс и делает его результат видимым каждому последующему вызывающему. Это примитив для «дорогой вещи, которая должна произойти максимум один раз, сколько бы воркеров ни стартовали параллельно».

## Обзор

- **Запуск один раз между воркерами.** Два воркера, наперегонки вызывающие `init($factory)`, запускают фабрику только у одного; проигравший ждёт и видит значение победителя.
- **Мемоизировано навсегда.** После инициализации `get()` возвращает значение, ничего не запуская.
- **Безопасно к реентрантности.** Вызов `init()` на том же Once изнутри его же фабрики бросает `DeadlockException` вместо зависания.
- **Shareable.** Экземпляры живут в реестре и путешествуют через захваты `use` и записи `Shared\Map`.

## Справочник API

```php
namespace OxPHP\Shared;

final class Once implements Shareable
{
    public function __construct();

    public function get(): mixed;                   // null, если ещё не задано
    public function isInitialized(): bool;
    public function trySet(mixed $value): bool;     // true, если этот вызов победил
    public function init(callable $factory): mixed; // запускает фабрику ровно один раз

    public function id(): int;
}
```

| Метод           | Возвращает    | Применение                                                       |
|-----------------|--------------|------------------------------------------------------------------|
| `get`           | значение или null | Чистое чтение; `null`, если никто ещё не инициализировал.    |
| `isInitialized` | bool         | Проверка без получения значения.                                 |
| `trySet`        | победитель?  | Прямой value-first init, когда значение уже в руках.             |
| `init`          | сохранённое значение | Init на основе фабрики; возвращает мемоизированное значение при каждом вызове. |
| `id`            | id реестра   | Корреляция логов / наблюдаемости.                                |

## Примеры

### Дорогой конфиг, загружаемый один раз на процесс

```php
<?php
$config = new OxPHP\Shared\Once();

oxphp_worker(function () use ($config) {
    $cfg = $config->init(function () {
        // Выполняется ровно в одном воркере; все остальные видят результат.
        return json_decode(file_get_contents('/etc/myapp.json'), true);
    });

    echo $cfg['greeting'];
});
```

### Инициализация «значением вперёд», когда значение уже известно

```php
<?php
$buildSha = new OxPHP\Shared\Once();

// Обычно загружается из build-time константы, а не вычисляется в рантайме.
if ($buildSha->trySet(getenv('GIT_SHA') ?: 'unknown')) {
    // Мы его записали.
}

// Все читают мемоизированное значение.
$sha = $buildSha->get();   // никогда не null после первого trySet выше
```

### Bootstrap соединения с базой данных

```php
<?php
$pool = new OxPHP\Shared\Once();

$conn = $pool->init(function () {
    return new PDO(getenv('DB_DSN'), getenv('DB_USER'), getenv('DB_PASS'), [
        PDO::ATTR_PERSISTENT => true,
    ]);
});
```

Для пула соединений с несколькими слотами см. [Shared\Pool](shared-pool.md) — `Once` даёт *одно* значение; `Pool` даёт N.

## Семантика и подводные камни

- **`get()` возвращает `null` до успеха `init()` / `trySet()`.** Отличайте «ещё не задано» от «задано в null» через `isInitialized()`.
- **Фабрика запускается максимум один раз на процесс.** Даже если она бросает, это считается попыткой — `Once` не повторяет. Оборачивайте повторяемую логику внутри фабрики сами.
- **Реентрантность бросает.** `init()` изнутри своей же фабрики поднимает `DeadlockException` с id в сообщении. Перестройте граф, чтобы внутренний вызов использовал другой `Once` или получал ещё-не-сохранённое значение иначе.
- **Возврат фабрики сериализуется в shared-safe форму.** Скаляры и вложенные массивы скаляров проходят; замыкания, ресурсы и PHP-объекты, не являющиеся `Shareable`, поднимают `TypeException`.

## Исключения

| Исключение               | Бросается                                                       |
|--------------------------|-----------------------------------------------------------------|
| `DeadlockException`      | `init()` вызвана рекурсивно на том же Once из её фабрики.       |
| `TypeException`          | Фабрика возвращает несериализуемое значение (замыкание, ресурс). |
| `StaleHandleException`   | Любой метод на хэндле, чья запись реестра была вытеснена.       |
| `UninitializedException` | `id()` на обёртке, которая не завершила `__construct`.           |

Если сама фабрика бросает, это исключение распространяется без изменений; Once остаётся неинициализированным, и следующий вызов `init` попробует снова.

## Наблюдаемость

См. [Shared Observability](../operations/shared-observability.md). Краткие отсылки:

- `GET /__ox_shared/entry?id=N` показывает `{ initialized: bool, type: "Once" }` плюс превью сохранённого значения, когда доступно.
- Prometheus `oxphp_shared_once_initialized{once_id="…"}` gauge (0 или 1).

## Когда не использовать

- **Значения, которые меняются после создания.** `Once` — write-once. Используйте `Shared\Mutex` или `Shared\Map`, когда хранимое состояние мутирует.
- **Локальное состояние на воркер.** Статические свойства классов или модульные глобалы дешевле, когда значение не нужно разделять.
- **Дорогие вычисления *на запрос*.** Кэшируйте внутри запроса, а не в разделяемом состоянии — иначе получите утечку памяти.
