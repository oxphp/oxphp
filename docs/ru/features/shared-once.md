# Shared\Once

`OxPHP\Shared\Once` запускает инициализирующее замыкание ровно один раз на весь процесс и делает его результат видимым каждому последующему вызывающему. Это примитив для «дорогой вещи, которая должна произойти максимум один раз, сколько бы воркеров ни стартовали параллельно».

## Обзор

- **Запуск один раз между воркерами.** Два воркера, наперегонки вызывающие `getOrInit($factory)`, запускают фабрику только у одного; проигравший блокируется и получает значение победителя.
- **Автомат из четырёх состояний.** Ячейка бывает `Uninitialized`, `Pending` (фабрика выполняется прямо сейчас), `Ready` или `Poisoned`. Читается через `status()`.
- **Никакого неоднозначного null.** `get()` бросает на незаданной ячейке вместо возврата `null`, поэтому сохранённый `null` — это настоящее значение, а не «отсутствует».
- **Безопасно к реентрантности.** Вызов `getOrInit()` на том же Once изнутри его же фабрики бросает `DeadlockException` вместо зависания.
- **Настраиваемая политика сбоя.** По умолчанию упавшая фабрика сбрасывает ячейку, чтобы следующий вызов мог повторить. Режим `Poison` делает упавшую фабрику терминальной — ячейка отключается навсегда.
- **Shareable.** Экземпляры живут в реестре и путешествуют через захваты `use` и записи `Shared\Map`.

## Справочник API

```php
namespace OxPHP\Shared;

final class Once implements Shareable
{
    public function __construct(Once\FailureMode $onFactoryError = Once\FailureMode::Reset);

    public function get(): mixed;                    // бросает, если не Ready
    public function status(): Once\Status;           // никогда не бросает
    public function trySet(mixed $value): bool;      // true, если этот вызов победил
    public function getOrInit(callable $factory): mixed; // запускает фабрику максимум один раз

    public function id(): int;
}

namespace OxPHP\Shared\Once;

enum Status { case Uninitialized; case Pending; case Ready; case Poisoned; }
enum FailureMode: int { case Reset = 0; case Poison = 1; }
```

| Метод       | Возвращает      | Применение                                                              |
|-------------|-----------------|------------------------------------------------------------------------|
| `get`       | сохранённое значение | Чтение значения, которое заведомо `Ready`. Бросает на uninit / pending / poison. |
| `status`    | `Once\Status`   | Интроспекция / диагностика. Никогда не бросает (безопасный наблюдатель poison). |
| `trySet`    | победитель?     | Push-модель init для уже готового значения (без побочной аллокации ресурса). |
| `getOrInit` | сохранённое значение | Pull-модель init; канонический race-free примитив.                |
| `id`        | id реестра      | Корреляция логов / наблюдаемости.                                       |

## Примеры

### Дорогой конфиг, загружаемый один раз на процесс

```php
<?php
$config = new OxPHP\Shared\Once();

oxphp_worker(function () use ($config) {
    $cfg = $config->getOrInit(function () {
        // Выполняется ровно в одном воркере; остальные блокируются и видят результат.
        return json_decode(file_get_contents('/etc/myapp.json'), true);
    });

    echo $cfg['greeting'];
});
```

`getOrInit()` — паттерн, защищённый от cache-stampede: под всплеском одновременных первых обращений фабрика выполняется ровно один раз *при успехе*, и каждый вызывающий — включая проигравших гонку — получает значение победителя. Если фабрика-победитель бросает в режиме `Reset`, следующий заблокированный вызывающий становится инициализатором и повторяет — поэтому *устойчиво* падающая фабрика под нагрузкой ретраит последовательно, а не разворачивается параллельно. Если сбой должен быть терминальным, используйте режим `Poison` (ниже).

### Ветвление по состоянию без запуска init

```php
<?php
use OxPHP\Shared\Once\Status;

$cfg = new OxPHP\Shared\Once();

$report = match ($cfg->status()) {
    Status::Ready        => $cfg->get(),
    Status::Pending      => 'инициализируется…',
    Status::Uninitialized => 'не запущено',
    Status::Poisoned     => 'загрузка конфига упала',
};
```

`status()` — для интроспекции: он никогда не запускает фабрику и никогда не бросает, даже на отравленной ячейке. Чтобы реально получить значение race-free, вызывайте `getOrInit()`.

### Инициализация «значением вперёд», когда значение уже известно

```php
<?php
$buildSha = new OxPHP\Shared\Once();

// Простое значение без побочных эффектов приобретения — trySet здесь уместен.
$buildSha->trySet(getenv('GIT_SHA') ?: 'unknown');

$sha = $buildSha->get();   // Ready после trySet выше
```

Используйте `trySet()` только для значений без side-effect-приобретения. Для ресурсов (соединения, файловые дескрипторы, сокеты) используйте `getOrInit()`: `trySet()`, проигравший гонку, просто отдаёт обычное значение сборщику мусора, а ресурс, приобретённый *до* проигранной гонки, утечёт.

Возврат `false` означает, что ячейка уже `Ready` **или** `Pending` — он *не* гарантирует, что последующий `get()` пройдёт: `Pending`-фабрика в другом потоке ещё может упасть и сбросить ячейку (в режиме `Reset`). Не пишите `if (!$o->trySet($v)) { $x = $o->get(); }`; если нужно значение — вызывайте `getOrInit()`.

### Bootstrap соединения с базой данных

```php
<?php
$pool = new OxPHP\Shared\Once();

$conn = $pool->getOrInit(function () {
    return new PDO(getenv('DB_DSN'), getenv('DB_USER'), getenv('DB_PASS'), [
        PDO::ATTR_PERSISTENT => true,
    ]);
});
```

Для пула соединений с несколькими слотами см. [Shared\Pool](shared-pool.md) — `Once` даёт *одно* значение; `Pool` даёт N.

### Fail-fast на сломанном предусловии

```php
<?php
use OxPHP\Shared\Once\FailureMode;

// Если эта инициализация упадёт, приложение не восстановится — отравите ячейку,
// чтобы каждый последующий доступ падал громко, а не повторял обречённую фабрику.
$secrets = new OxPHP\Shared\Once(onFactoryError: FailureMode::Poison);

$secrets->getOrInit(fn () => loadSecretsOrThrow());
```

## Семантика и подводные камни

- **`get()` бросает, когда ячейка не `Ready`.** `UninitializedException` для пустой или `Pending` ячейки, `PoisonedException` для отравленной. Используйте `status()` для ветвления без исключения или `getOrInit()` для безопасного получения значения.
- **Фабрика запускается максимум один раз на успешную инициализацию.** Параллельные вызывающие блокируются на победителе; свою копию они не запускают.
- **Политика сбоя задаётся при конструировании, а не на вызов.** `Reset` (по умолчанию) возвращает ячейку в `Uninitialized` при сбое фабрики, чтобы следующий вызов повторил; `Poison` делает ячейку терминально `Poisoned`. В обоих режимах исключение фабрики перебрасывается *текущему* вызывающему.
- **Poison честен межпотоково, но не объектно-идентичен.** Объект PHP-исключения не может пересечь границу воркер-потоков, поэтому отравленная ячейка захватывает класс, сообщение и код сбоя. Последующие вызывающие на любом потоке получают свежий `PoisonedException` с этой информацией — те же детали, не тот же объект.
- **Реентрантность бросает.** `getOrInit()` изнутри своей же фабрики поднимает `DeadlockException`. Перестройте граф так, чтобы внутренний вызов использовал другой `Once`.
- **Полный диапазон значений.** Скаляры, массивы и вложенные `Shareable`-значения хранятся и читаются обратно. Замыкания, ресурсы и PHP-объекты, не являющиеся `Shareable`, поднимают `TypeException`.

## Исключения

| Исключение               | Бросается                                                          |
|--------------------------|-------------------------------------------------------------------|
| `UninitializedException` | `get()` на ячейке `Uninitialized` или `Pending`.                  |
| `PoisonedException`      | `get()` / `getOrInit()` / `trySet()` на ячейке `Poisoned`.        |
| `DeadlockException`      | `getOrInit()` вызвана рекурсивно на том же Once из её фабрики.     |
| `TypeException`          | Сохраняемое значение несериализуемо (замыкание, ресурс).          |
| `StaleHandleException`   | Любой метод на хэндле, чья запись реестра была вытеснена.          |

Если сама фабрика бросает, это исключение распространяется без изменений текущему вызывающему. В режиме `Reset` ячейка остаётся неинициализированной, и следующий `getOrInit` повторит; в режиме `Poison` ячейка становится отравленной.

## Наблюдаемость

См. [Shared Observability](../operations/shared-observability.md). Краткие отсылки:

- `GET /__ox_shared/entry?id=N` показывает `{ status: "uninitialized" | "pending" | "ready" | "poisoned", type: "Once" }` плюс превью сохранённого значения, когда `ready`.

## Когда не использовать

- **Значения, которые меняются после создания.** `Once` — write-once. Используйте `Shared\Mutex` или `Shared\Map`, когда хранимое состояние мутирует.
- **Локальное состояние на воркер.** Статические свойства классов или модульные глобалы дешевле, когда значение не нужно разделять.
- **Дорогие вычисления *на запрос*.** Кэшируйте внутри запроса, а не в разделяемом состоянии — иначе получите утечку памяти.
