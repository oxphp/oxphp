---
title: Пользовательские страницы ошибок
description: Предзагруженные HTML-страницы ошибок для ответов 4xx и 5xx
---

OxPHP может отдавать пользовательские HTML-страницы ошибок для ответов 4xx и 5xx. Страницы загружаются с диска один раз при запуске и обслуживаются из памяти на горячем пути.

## Настройка

| Переменная | Описание | По умолчанию |
|------------|----------|--------------|
| `ERROR_PAGES_DIR` | Директория с HTML-файлами страниц ошибок | *(не задана)* |

```bash
ERROR_PAGES_DIR=/var/www/errors
```

Если переменная не задана, ошибочные ответы содержат стандартное текстовое тело (например, `404 Not Found`).

## Именование файлов

Файлы страниц ошибок должны следовать соглашению `{status}.html`, где `{status}` — HTTP-код состояния:

```
errors/
  403.html
  404.html
  500.html
  502.html
  503.html
  529.html
```

Загружаются только коды состояния в диапазоне 400–599. Файлы с нечисловыми именами, именами за пределами этого диапазона или с расширениями, отличными от `.html`, игнорируются.

## Как это работает

### Загрузка

При запуске OxPHP читает указанную директорию и загружает каждый валидный файл `{status}.html` в `HashMap<u16, Bytes>`. Содержимое файлов хранится как байтовые буферы со счётчиком ссылок для отдачи без копирования. Каждая загруженная страница логируется на уровне `info`.

Если директория не существует или недоступна для чтения, записывается предупреждение и сервер запускается без пользовательских страниц ошибок.

### Обслуживание

`ErrorPagesHandler` работает как обработчик события `ResponseBuilding` с приоритетом **60**. Это помещает его после основной обработки, но перед обработчиками заголовка сервера и журнала доступа (приоритет 100).

Для каждого ответа с кодом состояния 400 и выше обработчик проверяет предзагруженные страницы. Если подходящая страница найдена, тело ответа заменяется пользовательским HTML-содержимым и заголовок `Content-Type` устанавливается в `text/html; charset=utf-8`.

Ответы с кодами 2xx или 3xx не затрагиваются.

### Пример страницы

Минимальная страница ошибки 404:

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="utf-8">
  <title>404 - Page Not Found</title>
</head>
<body>
  <h1>Page Not Found</h1>
  <p>The requested page does not exist.</p>
</body>
</html>
```

Сохраните этот файл как `404.html` в директории, указанной в `ERROR_PAGES_DIR`.

## Производительность

Страницы ошибок загружаются в память один раз при запуске. Отдача пользовательской страницы ошибки — это `HashMap::get()` с последующим `Bytes::clone()` (атомарный инкремент счётчика ссылок). Дисковый ввод-вывод при обработке запросов не выполняется.

## Ограничения

Пользовательские страницы ошибок применяются только к ответам, проходящим через обычный конвейер обработки запросов. Ответы, установленные как ранние возвраты (например, 429 от ограничителя частоты запросов), обходят событие `ResponseBuilding` и не затрагиваются пользовательскими страницами ошибок.
