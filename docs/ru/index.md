# Документация OxPHP

OxPHP — высокопроизводительный сервер PHP-приложений, заменяющий nginx + PHP-FPM единым бинарным файлом — со встроенными TLS, сжатием Brotli, ограничением частоты запросов, проверками состояния, метриками Prometheus, SSE-стримингом и режимом постоянных воркеров.

## Почему OxPHP

Типичное PHP-приложение в продакшене — это несколько контейнеров: nginx, PHP-FPM, иногда ещё TLS-прокси и exporter для метрик. Конфигурация размазана между ними, и чтобы всё заработало вместе, нужно синхронизировать настройки сокетов, таймаутов и путей. OxPHP заменяет весь этот стек [одним контейнером](getting-started/docker.md). Внутри — один процесс, который принимает HTTP-соединения, исполняет PHP и отдаёт статику.

Сервер работает из коробки с разумными значениями по умолчанию. Донастройка — через [переменные окружения](operations/configuration.md): [TLS](features/tls.md) включается двумя переменными (`TLS_CERT`, `TLS_KEY`), [ограничение частоты запросов](features/rate-limiting.md) — одной (`RATE_LIMIT`), [сжатие Brotli](features/compression.md) включено по умолчанию. Не нужно редактировать конфиги nginx или собирать отдельные модули.

На выделенном [внутреннем порту](features/internal-server.md) доступны [проверки состояния](operations/health-checks.md) (`/health`), [метрики Prometheus](operations/metrics.md) (`/metrics`) и снимок конфигурации (`/config`). Этого достаточно для Kubernetes liveness/readiness проб и подключения Grafana без дополнительных sidecar-контейнеров.

[Логи](features/access-logging.md) — структурированный JSON: метод, путь, статус, время ответа, [ID запроса](features/request-ids.md) — в каждой строке. Их удобно парсить в Loki, Elasticsearch или любом другом инструменте без дополнительных grok-паттернов.

Если хочется попробовать [режим воркеров](features/worker-mode.md), где PHP-процесс не пересоздаётся на каждый запрос, — достаточно одной переменной окружения `INDEX_FILE=worker.php`. Фреймворк инициализируется один раз, а дальше обрабатывает тысячи запросов без повторной загрузки. Вернуться к классическому режиму — убрать переменную.

А ещё в OxPHP есть возможности, которые обычно требуют отдельных инструментов или сторонних библиотек:

- **[Четыре режима маршрутизации](features/routing.md)** — файловый, фреймворк, SPA и воркеры
- **[Ранний ответ](features/early-response.md)** — немедленная отправка ответа с продолжением фоновой обработки
- **[Режим воркеров](features/worker-mode.md)** — постоянные PHP-процессы с [мультиплексированием файберов](features/fiber-multiplexing.md)
- **[SSE-стриминг](features/sse.md)** — Server-Sent Events в реальном времени из PHP
- **[Асинхронные промисы](features/async-promises.md)** — фоновое выполнение PHP-замыканий без блокировки воркера
- **[Декораторы](features/decorators.md)** — перехват вызовов через атрибуты PHP 8
