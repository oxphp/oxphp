# Документация OxPHP

OxPHP — высокопроизводительный сервер PHP-приложений, заменяющий nginx + PHP-FPM единым бинарным файлом — со встроенными TLS, сжатием Brotli, ограничением частоты запросов, проверками состояния, метриками Prometheus, SSE-стримингом и режимом постоянных воркеров.

## Почему OxPHP

Традиционное развёртывание PHP требует множества компонентов: веб-сервер, менеджер процессов, TLS-прокси и отдельные инструменты для метрик и ограничения частоты запросов. OxPHP сворачивает весь этот стек в один бинарный файл.

- **Единый бинарный файл** — без nginx, без PHP-FPM, без менеджера процессов. Один контейнер запускает всё приложение.
- **Встроенный TLS** — терминируйте TLS напрямую без обратного прокси. Настройка с помощью двух переменных окружения.
- **Сжатие Brotli** — сжатие текстовых ответов включено по умолчанию с настраиваемыми уровнями качества.
- **Ограничение частоты запросов** — встроенное ограничение по IP с настраиваемыми лимитами и временными окнами.
- **Проверки состояния** — эндпоинты `/health`, `/metrics` и `/config` на выделенном внутреннем порту для проб Kubernetes и систем мониторинга.
- **Метрики Prometheus** — счётчики запросов, время ответа, ожидание в очереди, статистика пула воркеров, экономия при сжатии и многое другое по адресу `/metrics`.
- **Отдача статических файлов** — кэширование в памяти, автоматическое определение MIME-типов, заголовки ETag/Last-Modified и настраиваемое время жизни кэша без дополнительной конфигурации.
- **Режим воркеров** — постоянные PHP-процессы, выполняющие инициализацию один раз и обрабатывающие тысячи запросов, что устраняет накладные расходы на запуск для каждого запроса в фреймворках Laravel и Symfony.
- **SSE-стриминг** — Server-Sent Events в реальном времени, передаваемые из PHP в браузер без опроса.
- **Ранний ответ** — немедленная отправка HTTP-ответа с продолжением обработки в фоне.
- **Четыре режима маршрутизации** — традиционное отображение файлов, фронт-контроллер фреймворка (`index.php`), SPA-фолбэк (`index.html`) и режим воркеров.
- **Асинхронные промисы** — выполнение PHP-замыканий в выделенном пуле потоков с ожиданием результатов без блокировки воркера.
- **Декораторы** — перехват вызовов функций и методов с помощью атрибутов PHP 8 для логирования, замеров времени, кэширования и контроля доступа.
- **W3C Trace Context** — передача заголовков распределённой трассировки от вышестоящих сервисов в PHP через `$_SERVER`.
- **OpenTelemetry** — экспорт спанов запросов в Jaeger, Grafana Tempo, Zipkin или любой OTLP-совместимый бэкенд.

## Быстрый старт

Запустите OxPHP за 30 секунд с Docker:

```dockerfile
FROM ghcr.io/oxphp/oxphp:0.1.0

COPY --chown=www-data:www-data . /var/www/html
```

```bash
docker build -t my-app .
docker run -p 8080:80 my-app
curl http://localhost:8080/
```

Образ OxPHP включает серверный бинарный файл, PHP 8.4, OPcache с JIT и все необходимые зависимости. Код вашего приложения размещается в `/var/www/html`, корень документов по умолчанию — `/var/www/html/public`.

Полное пошаговое руководство см. в разделе [Быстрый старт](getting-started/quick-start.md).
