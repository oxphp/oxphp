# Класс Worker

`OxPHP\Server\Worker` — это единый рантайм-обработчик для всего, что связано с одним OS-потоком воркера OxPHP. Это финальный класс без состояния, представляющий собой обёртку над thread-local-состоянием моста; он регистрируется самим SAPI-расширением и доступен всегда — как в традиционном режиме, так и в [режиме воркера](../features/worker-mode.md). Каждый вызов читает живое состояние рантайма напрямую; сам объект ничего не кэширует.

`Worker::current()` возвращает синглтон в пределах одного OS-потока: два вызова в одном потоке всегда возвращают один и тот же экземпляр.

## Краткий справочник

| Метод | Описание |
|-------|----------|
| `Worker::current(): self` | Возвращает синглтон-обработчик для текущего OS-потока. |
| `Worker::isWorkerMode(): bool` | Возвращает `true`, если сервер работает в режиме воркера (т. е. задан `WORKER_FILE`). |
| `getId(): int` | Числовой идентификатор воркера в диапазоне `0..N-1` для текущего OS-потока. |
| `getStartTime(): float` | Unix-метка времени (в секундах) запуска OS-потока воркера. |
| `getRequestCount(): int` | Количество запросов, обработанных этим OS-потоком, начиная с 1. Растёт в обоих режимах. |
| `getMemoryUsage(): int` | Текущее потребление памяти PHP в байтах (`zend_memory_usage(0)`). |
| `getRss(): int` | Размер резидентного набора процесса (RSS) в байтах. Не кэшируется — вызывайте не чаще одного раза за запрос. |
| `getMaxMemoryBytes(): int` | Сконфигурированный лимит памяти в байтах. `0` означает «без лимита». |
| `serve(callable $h): void` | Входит в цикл обработки запросов. Бросает `InvalidServeContextException` вне режима воркера. |

## Матрица режимов

| Метод | Традиционный режим | Режим воркера |
|-------|--------------------|---------------|
| `current()` | Синглтон в пределах OS-потока. | Синглтон в пределах OS-потока. |
| `isWorkerMode()` | `false` | `true` |
| `getId()` | Индекс OS-потока в пуле воркеров. | Индекс OS-потока в пуле воркеров. |
| `getStartTime()` | Время запуска OS-потока (обычно — старт сервера). | Время запуска OS-потока. |
| `getRequestCount()` | Начинается с 1, инкрементируется при повторном использовании того же OS-потока (`1, 2, 3, …`). | Начинается с 1, инкрементируется на каждый запрос, обработанный воркером. |
| `getMemoryUsage()` | Текущая память PHP на момент вызова. | Текущая память PHP на момент вызова. |
| `getRss()` | Текущий RSS процесса. | Текущий RSS процесса. |
| `getMaxMemoryBytes()` | `0` (лимит recycle не применяется). | Значение `WORKER_MAX_MEMORY_MIB` × 1 МиБ или `0`, если не задано. |
| `serve(callable)` | Бросает `OxPHP\Server\Exception\InvalidServeContextException`. | Входит в цикл обработки запросов. |

## Примеры

### Контекст логирования по воркеру

Помечайте каждую строку лога идентификатором воркера и счётчиком запросов на поток, чтобы соотносить трафик с конкретным воркером.

```php
<?php
$worker = OxPHP\Server\Worker::current();

$logger->info('handling request', [
    'worker_id'      => $worker->getId(),
    'request_number' => $worker->getRequestCount(),
]);
```

### Однократная инициализация для OS-потока

`getRequestCount()` начинается с 1, поэтому первый запрос, обработанный любым потоком, видит значение `1`. Это переносимое место для отложенной инициализации, которая должна выполняться ровно один раз на поток.

```php
<?php
$worker = OxPHP\Server\Worker::current();

if ($worker->getRequestCount() === 1) {
    bootstrap();
}
```

### Точка входа воркера

В скрипте `WORKER_FILE` вызывайте `serve()` для входа в цикл обработки запросов.

```php
<?php
require __DIR__ . '/../vendor/autoload.php';

OxPHP\Server\Worker::current()->serve(function () {
    handleRequest();
});
```

### Наблюдение за RSS

`getRss()` возвращает текущий размер резидентного набора процесса в байтах. Под капотом — настоящий системный вызов: дешёвый, но не бесплатный. Читайте его не чаще одного раза за запрос.

```php
<?php
$worker = OxPHP\Server\Worker::current();
$rss = $worker->getRss();

$metrics->gauge('php_worker_rss_bytes', $rss, [
    'worker_id' => (string) $worker->getId(),
]);
```

## Миграция с функций `oxphp_*`

Старые свободные функции по-прежнему доступны и используют то же внутреннее состояние — они не объявлены устаревшими. Новый код стоит писать на классе API для большей наглядности и единообразия.

| Старая функция | Класс API |
|----------------|-----------|
| `oxphp_is_worker()` | `OxPHP\Server\Worker::isWorkerMode()` |
| `oxphp_worker_id()` | `OxPHP\Server\Worker::current()->getId()` |
| `oxphp_worker(callable)` | `OxPHP\Server\Worker::current()->serve(callable)` |

## Замечания

- **`getRss()` не кэшируется.** Каждый вызов выполняет системный вызов (чтение `/proc/self/statm` на Linux, `getrusage(RUSAGE_SELF)` на macOS). Дёшево, но не бесплатно — вызывайте не чаще одного раза за запрос, обычно внутри обработчика метрик, а не в каждой строке лога.
- **Клонирование запрещено.** `clone $worker` бросает `\Error("Cloning OxPHP\\Server\\Worker is not allowed")`. Обработчик воркера представляет идентичность OS-потока; клонирование создавало бы ложное впечатление существования второго обработчика для того же потока.
- **Вне OxPHP-хоста** (например, когда расширение, линкующее SAPI, загружено в PHP CLI), `Worker::current()` всё равно возвращает экземпляр, но все геттеры возвращают значения нулевого состояния: `getId()` — `0`, `getStartTime()` — время запуска процесса, `getRequestCount()` — `0`, `getRss()` — текущий RSS, а `serve()` бросает `InvalidServeContextException`.
