title: Ідэнтыфікатары запытаў

---

Кожны запыт, апрацаваны OxPHP, атрымлівае ўнікальны ідэнтыфікатар запыту. Гэты ідэнтыфікатар з'яўляецца ў журналах доступу, журналах памылак і загалоўках адказаў, забяспечваючы адзінае значэнне для карэляцыі запыту на ўсіх узроўнях стэка.

## Канфігурацыя

Генерацыя ідэнтыфікатараў запытаў заўсёды ўключана. Канфігурацыя не патрабуецца.

## Як гэта працуе

Апрацоўшчык падзей `RequestIdGenerator` працуе з прыярытэтам **-100** (найменшае значэнне прыярытэту, што азначае, што ён запускаецца першым). Ён альбо захоўвае ўваходны ідэнтыфікатар запыту, альбо генеруе новы.

### Праходжанне

Калі ўваходны запыт змяшчае загаловак `X-Request-ID`, яго значэнне выкарыстоўваецца як ёсць. Гэта дазваляе вышэйстаячым балансіроўшчыкам нагрузкі або API-шлюзам прызначаць ідэнтыфікатары запытаў, якія распаўсюджваюцца праз OxPHP.

### Генерацыя

Калі загаловак `X-Request-ID` адсутнічае, OxPHP генеруе ідэнтыфікатар у фармаце:

```
{timestamp:08x}{counter:08x}
```

- **timestamp** (8 шаснаццатковых сімвалаў): бягучы часавы штамп Unix у секундах, абрэзаны да 32 біт
- **counter** (8 шаснаццатковых сімвалаў): агульнапрацэсны атамарны лічыльнік з поўным дыяпазонам `u32`

Гэта стварае 16-сімвальны радок у ніжнім рэгістры шаснаццатковай сістэмы. Напрыклад: `67890abc00000042`.

Лічыльнік выкарыстоўвае парадак памяці `Relaxed`, бо ўнікальнасць гарантуецца атамарным інкрэментам — сувязь happens-before з іншымі дадзенымі не патрэбна.

### Загаловак адказу

Ідэнтыфікатар запыту ўключаецца ў кожны HTTP-адказ як загаловак `X-Request-ID`. Ён усталёўваецца апрацоўшчыкам загалоўкаў сервера падчас падзеі `ResponseBuilding`.

## Доступ да ідэнтыфікатара запыту ў PHP

Ідэнтыфікатар запыту даступны ў PHP праз функцыю `oxphp_request_id()`, якую прадастаўляе PHP-пашырэнне OxPHP:

```php
<?php
$requestId = oxphp_request_id();
header("X-Correlation-ID: $requestId");
error_log("Processing request $requestId");
```

Функцыя вяртае той самы 16-сімвальны шаснаццатковы радок (або значэнне праходжання), які з'яўляецца ў загалоўку адказу і журналах доступу.

## Карэляцыя ў журнале доступу

Кожны запіс журнала доступу ўключае поле `request_id`:

```json
{
  "request_id": "67890abc00000042",
  "method": "GET",
  "path": "/api/users",
  "status": 200,
  "duration_us": 1234,
  "remote_addr": "10.0.0.1:54321"
}
```

Вы можаце фільтраваць журналы па ідэнтыфікатару запыту, каб прасачыць поўны жыццёвы цыкл аднаго запыту, уключаючы любыя памылкі PHP, якія спасылаюцца на той самы ідэнтыфікатар.
